# Screenshot shot list

Save each image in this folder with the exact file name below. The README links them with absolute
`https://raw.githubusercontent.com/drakethos/DrakeReskinIt/main/docs/images/<file>` URLs so they show on Hexium too.

Tips: 1920x1080 (or crop to the subject), PNG, daylight, plain background, HUD hidden for character shots
(F3 / devcommands `hidehud`), the same character across shots.

| File | README section | What to capture |
|---|---|---|
| `hero.png` | Top | Reskin menu open over the inventory, a striking item mid-reskin (recolored, different model in the preview). |
| `before-after.png` | What it can do | Side by side: same character and pose, plain gear vs. reskinned + recolored gear. |
| `tabs.png` | How to use it | Close crop of the Shift + right-click tab bar: Rename / Paper / Reskin. |
| `menu-callouts.png` | The Reskin menu | Full menu with numbers 1-6 drawn on: mode buttons, grid, preview rows + badge, Color buttons, presets, Apply/Reset. |
| `color-picker.png` | The Reskin menu | Color picker popup open over the menu, bold color picked so the preview shows it. |
| `hotbar.png` | Inventory and hotbar | Hotbar with 3-4 reskinned / recolored icons, ideally next to a plain original. |
| `weapon-shield.png` | On your character | Third person, holding a reskinned, clearly recolored weapon and shield. |
| `armor.png` | On your character | Full body in recolored armor (chest, legs, helmet, cape), side angle. |
| `locked.png` | Locked looks | Grid with unlocked tiles and dark silhouettes, hover tooltip showing a lock reason. |
| `config.png` | Configuration | Gale / r2modman config editor, `03 - Features` expanded. |

Optional: `apply.gif` (pick a model, press Apply, short loop) and `multiplayer.png` (two players, the other sees the reskin).
